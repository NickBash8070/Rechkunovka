# Локальный запуск и правила выгрузки

Проверено 15 октября 2026 года. Основной источник согласованных требований — `AGENTS.md`: читать всю историю, применять явно заменяющие уточнения, а не устаревшие пункты README. Не менять дизайн при подготовке выгрузки.

## Локальный просмотр

Из папки `site`: `npm run dev -- --host 127.0.0.1 --port 4176 --strictPort`.
Адрес: http://127.0.0.1:4176/ . Открытие и первый экран подтверждены в браузере Codex. В этой среде сервер следует запускать вне сетевых ограничений песочницы: ограниченный запуск сообщал готовность, но соединение из браузера завершалось тайм-аутом.

## Согласованные основы

- Сохранять 16 секций, исходные тексты, цифры, фотографии и геометрию контуров. Использовать адаптивную семантическую разметку Grid/Flex.
- Только Nimbus Sans Regular/Bold; шесть общих ролей H1–H5/Body и служебные роли из `src/styles/typography.css`. Указания README о P052 устарели.
- Шкала отступов 8/16/24/32/48/64/96/128px; общий промежуток карточек 24px, padding 32px desktop / 24px tablet и phone. FAQ также использует этот padding, заменяя прежние 16px.
- Шапка 60px, умное скрытие/появление, «МЕНЮ» на всех экранах с гамбургером. Навигация без подчёркиваний; hover/focus/current #647443. Якорь приземляется границей секции в y=0, заменяя прежний сдвиг 60px.
- Подзаголовок hero: «Два инвестиционных участка с продуктовой концепцией», Body, обычный регистр. KPI категории: «4 звезды» и «целевая категория».
- Подписи контуров — белые круги 132px справа сверху вне участков, тёмный текст в три строки, появление после анимации. Узкие схемы резервируют отдельный верхний ряд для подписи. Декор внутри контуров — регулярные точки, без деревьев.
- Общие семантические линейные иконки; стрелки через ArrowIcon. Свежие уточнения масштаба/выравнивания в AGENTS.md имеют приоритет.
- Карта MapLibre 6.14.0, OpenFreeMap/OpenMapTiles, ленивое подключение, сохранённый экземпляр, обязательная атрибуция. Основной маркер «Речкуновская зона отдыха», без ссылки «Посмотреть участки»; сохранить увеличение по выбору маркера.
- Анимации учитывают reduced-motion; последовательное появление карточек с шагом 100ms. Исходные фото и MP4 не изменять. Полные изображения загружать по открытию, семь MP4 — только по явному Play, один плеер с выгрузкой при закрытии/переключении.
- Новые постоянные решения записывать в AGENTS.md; точные дополнительные требования по компонентам остаются в этом файле.

## Сборка и передача

1. Выполнить `npm run build` и `npm run test:sites`. Общая проверка: `node --test tests/*.test.mjs`.
2. Для статического хостинга передавать содержимое `dist/client`; пути рассчитаны на корень домена.
3. Для Sites сохранять `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, `tests/sites-worker.test.mjs`. Сборка обязана содержать `dist/client/index.html`, `dist/server/index.js`, `dist/.openai/hosting.json`. D1/R2 сейчас null.
4. На статическом хостинге настроить SPA fallback юридических маршрутов `/privacy` и `/personal-data-consent`. Они уже описаны в `vercel.json`.
5. `.vercel` содержит локальную привязку проекта: не включать её в публичный пакет или Git.
6. После публикации проверить HTTP Range для видео на выбранном хостинге.
