# Речкуновская зона отдыха

Готовый адаптивный frontend по 16-страничной презентации `Речкуновская_для_Петра_v9.pdf`.

## Правила продолжения работы

Согласованные требования сохранены в `AGENTS.md`. Файл содержит историю решений: явно заменённые требования не применяются; более свежие уточнения имеют приоритет в своей области. Новые постоянные решения записываются туда же.

- Сохранять все 16 секций, исходные тексты, числа, фотографии, цвета и встроенные Nimbus Sans/P052. Использовать цельные текстовые блоки и адаптивные Grid/Flex-композиции.
- Отступы задавать шкалой 8/16/24/32/48/64/96/128px. Между карточками — общий `--card-gap` 24px; ритм секций — 128/96/64px, внутренние отступы карточек — 32px на desktop и 24px на tablet/mobile. Сохранять адаптивные боковые поля и согласованные оптические исключения.
- Шапка фиксированная, 60px. Навигация включает контакты; переходы учитывают шапку. Все интерфейсные стрелки — общий `ArrowIcon`, 24×24px и stroke 2px.
- Первый заголовок — две строки «РЕЧКУНОВСКАЯ» / «ЗОНА ОТДЫХА». Превью видео — 16:9; мобильный первый экран использует компактную горизонтальную карточку.
- Типографика задаётся только в `src/styles/typography.css`: шесть плавных визуальных ролей H1–H5 и Body через классы `type-h1`…`type-h5`/`type-body`, независимо от HTML-тега. Общие служебные роли используют 12px/14px/16px. Старые локальные размеры и breakpoint overrides удалены. Для согласованных примечаний сохранена opacity .45. Отчёты: `../qa/typography-system-2026-10-13.md`, `../qa/typography-role-audit-2026-10-13.md`.
- Вход карточек выполняется последовательно с шагом 100ms; учитывать reduced-motion. Для маркера карты согласован повторяющийся пульс, для контуров участков — однократная прорисовка.
- Исходные фото и MP4 не изменять. Полные изображения концепции загружать только при открытии просмотра; MP4 — только по явному Play.
- Интерфейс изменять в `src/`; сохранять оболочку Sites и её проверки. Перед передачей в Sites выполнять сборку и `npm run test:sites`.

Текущее ограничение: форма готовит письмо для самостоятельной отправки, backend отсутствует. Юридические документы остаются черновиками до заполнения проверенных реквизитов в `src/legal/operator.js`. Также не предоставлены URL агентства и полная концепция на 154 страницы. После публикации нужно проверить HTTP Range для видео на выбранном хостинге.

Текущий локальный просмотр: http://127.0.0.1:4176/

## Запуск

Команды выполняются из папки `site`:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

Production-сборка и её просмотр:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4174
```

Для статического хостинга используется содержимое `dist/client`. Пути рассчитаны на корень домена. Сборка также содержит совместимую с Sites оболочку в `dist/server` и `dist/.openai`. Публикация не выполнялась.

## Реализация

- React 19.2 и Vite 6.4.2; зависимости зафиксированы в `package-lock.json`.
- Все 16 страниц сохранены как последовательные секции с якорной навигацией.
- Шапка высотой 60 px закреплена на всех устройствах; название набрано оригинальным Nimbus Sans Bold. В начале страницы она прозрачная, после прокрутки — белая с фирменным зелёным текстом и стрелкой. Якорные переходы учитывают её высоту.
- Единая семантическая HTML-разметка для desktop, tablet и mobile: цельные заголовки и абзацы, естественные переносы, Grid/Flex и высота секций по содержимому. Построчное позиционирование текста из PDF удалено.
- Адаптивная типографика, перестройка карточек и списков; оригинальные SVG-диаграммы и фотографии сохранены. Анимация применяется к целым текстовым блокам и карточкам.
- Nimbus Sans Regular/Bold и P052 Roman извлечены из PDF; системные замены не используются. Метрики webfont согласованы с PDF.
- SVG-графика загружается при приближении к viewport, ресурсы кешируются, изображения сохраняют исходное качество. Первый экран и его шрифты загружаются сразу.
- Кнопки, мобильное меню, просмотр 12 миниатюр концепции, форма, телефон и email работают. Диалоги закрываются кнопкой, Escape и кликом по фону.

## Контент и ограничения исходника

Видеооблёт подключён к галерее из семи разных роликов без звука. Открытие галереи и выбор превью загружают только постеры; MP4 запрашивается по явному Play. Работает один плеер, который останавливается и выгружается при переключении или закрытии. URL агентства и файл полной концепции на 154 страницы не предоставлены. Кнопки открывают соответствующее пояснение или переводят к запросу материалов; вымышленные адреса не добавлены.

Форма проверяет телефон и имя, затем готовит письмо на `burde@bk.ru`. Посетитель открывает и отправляет письмо в своём почтовом приложении. Сервер автоматического приёма заявок не подключён. Тестовые письма не отправлялись.

Исходная 16-страничная презентация доступна по `/rechnovka-presentation.pdf`. Это не документ полной концепции на 154 страницы.

## Структура

`src/components` — оригинальная графика, форма, галерея, анимация и общие элементы.

`src/sections` — извлечённые данные PDF и адаптивные композиции всех секций.

`src/styles` — оригинальные цвета и шрифты, адаптивная типографика и обычные потоковые композиции.

`src/assets` — исходные векторные фрагменты PDF; `public/assets` — оригинальные изображения; `public/fonts` — встроенные шрифты.

В родительской папке: `reference` — полный анализ PDF, `qa` — снимки и visual diff, `scripts` — извлечение и сравнение. Итоговый отчёт: `design-qa.md`.
