# Речкуновская зона отдыха

Готовый адаптивный frontend по 16-страничной презентации `Речкуновская_для_Петра_v9.pdf`.

Текущий локальный просмотр: http://127.0.0.1:4176/

## Запуск

Команды выполняются из папки `site`:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

Production-сборка и её просмотр:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4174
```

Для статического хостинга используется содержимое `dist/client`. Пути рассчитаны на корень домена. Сборка также содержит совместимую с Sites оболочку в `dist/server` и `dist/.openai`. Публикация не выполнялась.

## Реализация

- React 19.2 и Vite 6.4.2; зависимости зафиксированы в `package-lock.json`.
- Все 16 страниц сохранены как последовательные секции с якорной навигацией.
- Шапка высотой 60 px закреплена на всех устройствах; название набрано оригинальным Nimbus Sans Bold. В начале страницы она прозрачная, после прокрутки — белая с фирменным зелёным текстом и стрелкой. Якорные переходы учитывают её высоту.
- Единая семантическая HTML-разметка для desktop, tablet и mobile: цельные заголовки и абзацы, естественные переносы, Grid/Flex и высота секций по содержимому. Построчное позиционирование текста из PDF удалено.
- Адаптивная типографика, перестройка карточек и списков; оригинальные SVG-диаграммы и фотографии сохранены. Анимация применяется к целым текстовым блокам и карточкам.
- Nimbus Sans Regular/Bold и P052 Roman извлечены из PDF; системные замены не используются. Метрики webfont согласованы с PDF.
- SVG-графика загружается при приближении к viewport, ресурсы кешируются, изображения сохраняют исходное качество. Первый экран и его шрифты загружаются сразу.
- Кнопки, мобильное меню, просмотр 12 миниатюр концепции, форма, телефон и email работают. Диалоги закрываются кнопкой, Escape и кликом по фону.

## Контент и ограничения исходника

Видеооблёт подключён к галерее из шести элементов с одним общим роликом без звука; загрузка начинается при открытии галереи. URL агентства и файл полной концепции на 154 страницы не предоставлены. Кнопки открывают соответствующее пояснение или переводят к запросу материалов; вымышленные адреса не добавлены.

Форма проверяет телефон и имя, затем готовит письмо на `burde@bk.ru`. Посетитель открывает и отправляет письмо в своём почтовом приложении. Сервер автоматического приёма заявок не подключён. Тестовые письма не отправлялись.

Исходная 16-страничная презентация доступна по `/rechnovka-presentation.pdf`. Это не документ полной концепции на 154 страницы.

## Структура

`src/components` — оригинальная графика, форма, галерея, анимация и общие элементы.

`src/sections` — извлечённые данные PDF и адаптивные композиции всех секций.

`src/styles` — оригинальные цвета и шрифты, адаптивная типографика и обычные потоковые композиции.

`src/assets` — исходные векторные фрагменты PDF; `public/assets` — оригинальные изображения; `public/fonts` — встроенные шрифты.

В родительской папке: `reference` — полный анализ PDF, `qa` — снимки и visual diff, `scripts` — извлечение и сравнение. Итоговый отчёт: `design-qa.md`.

## Проверки

`npm run build` — успешная production-сборка без предупреждений.

`npm run test:sites` — 4/4 теста раздачи файлов и упаковки.

`node --test tests/*.test.mjs` — 13 тестов: структура всех 16 секций, сохранение 21 KPI и основных CTA, анимация, маска телефона, навигация и упаковка/раздача.

Предыдущая PDF-композиция проходила браузерные проверки; снимки сохранены в `../qa`. Текущая семантическая переработка проверена сборкой и тестами. Визуальная проверка в браузере пока недоступна из-за отказа автоматической проверки доступа к localhost; старые снимки не подтверждают новую вёрстку.
